### 玻璃

玻璃、沙子、水晶，都是二氧化硅
- 沙子、水晶是晶体
- 玻璃是非晶体


制作
- 二氧化硅加热融化后，冷却后难以再形成晶体，最后形成不规则的原子结构（玻璃）
- 原本要1300度才能融化石英。用硝石（碳酸钠）降低玻璃的融化温度（**助熔作用**），阿拉伯商人发现
- 法国人纳夫发明了制作大块玻璃的工艺，玻璃真正走进日常生活。
- 自然界的玻璃：
    - 闪电击中沙子，瞬间的高温形成玻璃
    - 火山喷发



为什么玻璃透明？
- 电子吸收光子，使物质变得不透明。（量子）
- 玻璃中，电子轨道差异很大，可见光不足以提供电子跃迁
- 但紫外线足以提供跃迁能力，因此玻璃可以隔绝紫外线
- 石头、木头，其电子轨道差足以吸收可见光，因此不透明

光学现象
- **折射** 玻璃中的光速不同
    - 显微镜、望远镜
- **着色** 玻璃不规则的原子结构，给其它元素留下空间
    - 常见有茶色、海蓝色
    - 日常家居中，过滤紫外线的功能也十分重要，防止家具老化


**玻璃的失透**：因为冷却不够快、杂质等原因，玻璃中出现大量微小的晶体，使玻璃变得浑浊、乳白。

**智能玻璃**：某些物理条件下（电压、温度、光照），改变透明度



玻璃的价值
- 天文学。伽利略用望远镜的观测，证明了地心说的错误。
- 显微镜。观察到了微生物
- 棱镜。牛顿破解了彩虹的秘密
- 化学。玻璃试管用来观察化学反应的过程，使化学成为系统科学。
    - 耐热玻璃
    - 各种不同形状的实验器皿

耐热玻璃
- 加入了氧化硼，氧化硼也很难结晶，并且抑制玻璃的热胀冷缩。

中国曾在造纸、陶瓷、金属上领先，唯独忽略了玻璃技术。
- 瓷器过于成功，挤占玻璃需求
- 中国以铅钡玻璃为主，适合做饰品；西方钠钙玻璃，适合做透明容器
- 纸窗成本低、易更换、适合木建筑，并且中国的纸便宜、质量好，东方建筑主要用纸窗。

镜子：17世纪的顶级奢侈品

**玻璃酒杯**：让人能看到酒的颜色。从此酒的色泽也是酒品质的重要因素了。

**光导纤维**：
- 1000公里同轴电缆需要500吨铜，仅需要几公斤石英
- 一对电话线支持1000路电话，一对光纤支持100亿路电话
- 解决光衰减问题：
    1. 极纯净的石英玻璃，减少吸收和散射
    2. 最优的波长（1550nm 附近）。太短散射严重，太长玻璃本身吸收能量。
    3. 每上百公里，加装光信号放大器



**耐摔的玻璃**
- 鲁伯特之泪：极强的内应力，
- 同样的原理：**钢化玻璃**。抗冲击性提升数倍，碎裂时裂纹迅速遍布全身，不伤人。
- **防弹玻璃**：玻璃添加树脂夹层，吸收冲击能量，分散冲击力
- **玻璃钢**：不是玻璃，是玻璃、树脂构成的高分子复合材料

屏幕面板
- 乔布斯，美国康宁玻璃，柔韧。
- 曲面屏幕
- 柔性屏幕：极薄 + 化学强化 + 消除缺陷，每个因素都带来强大的柔韧性

### 陶瓷

陶瓷：与岩石类似的成分和结构。硬度大、化学性质稳定。

目前只有两种类似的人造物：水泥和陶瓷

陶瓷的原料：黏土
- 黏土是岩石风化而来的
- 黏土与石英、长石混合后煅烧，变成性质与岩石一样的物质
- 温度升高后，水分蒸发，反应开始。
    - 高温形成晶体微粒
    - 原子移动，在晶体之间形成原子桥，使晶体群变成连续体
    - 石英与 Na、K 形成玻璃体，玻璃体熔液渗到晶体间的空隙中。
    - 这些与其它矿物一起，最终形成完整的结构：陶瓷
    - 温度不很高时，这种结构有很多空隙。事先在柸上涂上特别的灰粉，它们加热后变成玻璃态，封住小孔。这叫做 **上釉**
    - 上釉带来装饰新境界。也让陶瓷更容易清洗


陶器：
- 旧石器时代进入到新石器时代的标志
- 唐三彩：釉彩为黄、绿、白
- 紫砂器：紫砂泥制作的无釉西陶器


瓷器：产生于东汉（越窑的青瓷）
- 唐代高度成熟
- 宋代进一步提升，“宋代五大名窑”


陶器 vs 瓷器
- 陶器
    - 温度 800-1000
    - 晶体靠近不够紧密，产生的玻璃也不够多
    - 气孔多，表面粗糙，有一定的吸水性
    - 敲击发出闷响
    - 上釉能防止水分和气体进入空隙，但无法解决本身空隙多的问题
- 瓷器
    - 温度 1100-1300，原料是高岭土（一种特殊的黏土）
    - 玻璃相填充空隙，结构紧密，气孔少
    - 质地细腻，表面光滑，敲击发出脆响


陶瓷的文化属性，历史上的陶瓷出口与丝绸之路等。

新型陶瓷材料
- 陶瓷本身硬，但是脆。现代工艺可以改进使其强韧。

**压电陶瓷**，有 **压电效应**
- 灶台、打火机：机械能转换为电能
    - 穿甲弹：替换掉延迟引信的不足，使其爆炸更及时
- 超声波清洗剂。电能转换为机械能


![压电效应](/a/materials/压电效应.svg)




半导体陶瓷：根据温度、湿度、浓度、光照的变化，改变电阻。从而能把这些信号转换为电信号
- 酒驾检测仪：气敏陶瓷
- 烟雾报警器、瓦斯报警器
- 取暖器的控温元件
- 光控路灯
- 照相机的自动曝光装置

**透明陶瓷**
- 陶瓷不透明，并不是因为晶体本身不透明，而是因为气孔、晶界、杂质、粗糙的表面。用工艺消除这些因素，可以制作出透明玻璃
- 防闪光弹护目镜
- 高压钠灯：用氧化铝陶瓷（能抗住高温钠的腐蚀）
- 氧化铝陶瓷加入铁，形成一定的晶体结构。可以用电控制其是否透明

### 混凝土


![caption: 水泥的生产](/a/materials/水泥的生产.svg)


水泥的凝固
1. 加水后产生化学反应，变成凝胶状物质
    - 生成：水、碳酸钙原纤维
    - 这些纤维逐渐生长、交错，锁住水
2. 进一步变成固体
    - 外边的水逐渐挥发
    - 变成石头状
    - 这时要保持湿润：1）使水化反应继续，使其更坚固；2）防止过早失水开裂
3. 甚至数年之后，水化反应仍在继续


混凝土：水泥+水+砂+石子
- 砂：填充空隙
- 石子：构成骨架，承担载荷
- 原因是，纯水泥：
    - 成本高
    - 收缩更强，从而容易开裂
- 钢筋混凝土：钢筋+混凝土


古罗马人最早拥有混凝土
- 古罗马万神殿（公元前27年至25年）至今仍然是世界上最大的无钢筋的混凝土圆顶建筑。
- 古罗马停止使用混凝土后的1000年，这世界不再有混凝土



-----------------

混凝土的特点

材料的断裂方式
- **塑形断裂**。金属拉伸过程中，先经历很多位移（因此金属强度和韧性大）
- **脆性断裂**。玻璃破碎的典型方式，混凝土也是这种断裂方式


![caption: 断裂](/a/materials/断裂.png)


混凝土耐压，不耐拉：抗折强度是抗压强度的 1/5


![caption: 混凝土受力](/a/materials/混凝土受力.png)


钢筋混凝土：
- 混凝土与钢材，不仅没像想象那样水油不混合，反而还相互吸附
- 钢筋和混凝土的膨胀系数还巧合的近似（否则会导致结构解体）


![caption: 钢筋混凝土](/a/materials/钢筋混凝土.png)


钢筋混凝土的锈蚀
- 原本碱性环境，在钢筋表面形成钝化保护膜
- 建筑磨损、热胀冷缩，会让混凝土出现小裂痕
- 大量水从裂痕进入，侵蚀钢筋，使铁锈在混凝土内部扩散，造成更多裂纹
- **自愈混凝土**，加入一种嗜碱细菌和淀粉
    - 水分进入后，细菌吞噬淀粉，生成方解石凝胶，愈合裂缝



优雅的混凝土
- 混凝土+光导纤维：透光混凝土
- 自洁净混凝土：抗菌、除污垢、分解某类污染气体
- 水泥毯：纤维+混凝土。可以像毯子一样悬挂、卷曲、覆盖在不规则物品上，加水后硬化
- 水泥帆布：可以快速搭建救护所

### 金属


金属的神奇之处：不易断裂、可锻造、越敲越强韧
- 其它硬的材料（木头、石头）用力敲击会碎裂，而金属不会
- 可硬可软
    - 加热后变软，有可塑性
    - 加热越敲越强韧（打铁）
    - 冷却后再加热，又会反转以上过程，变软


金属的结构
- 晶体结构：多晶材料。金属包含许多小晶体
- 例如钢铁的晶粒一般为 $10^{-1}$mm - $10^{-3}$mm
- 金属的可塑性来自晶体内部的各种缺陷
    - **位错**，是一种晶体缺陷
    - 回形针可以掰弯，就来自位错
    - 金属熔点越高，金属键强度越大，位错越不容易移动，金属就越硬
    - 金属加热可以让位错移动，重新排列组合，变软，可以再次塑形为需要的形状
- 刀刃变钝：由于反复撞击，金属键被打断，或晶体滑移，使刀刃上出现细小的凹洞。


![caption: 位错](/a/materials/位错.jpg)


**合金**：加入其它金属，使位错不容易移动
- 因此合金通常比纯金属更坚硬
- 青铜：铜加入锡，使硬度提高了5倍

**人类用铁的历史**
- 自然界只有铜、金是自然存在的，其它都必需从矿石中提炼
- 最早的铁是陨铁
- 加热孔雀石得到铜
- 试着加热其它东西（铁矿石），得到铁。
    - 但是碳会嵌入到铁晶体中
    - 含碳量太高，剑容易断
    - 含碳量太低，剑容易弯
- **锤炼钢铁**：不断锻打的方式挤出碳渣，铁就越来越强韧


**铁与钢**
- 铁硬度高，钢强度高
- 含碳量高于 2.1% 的铁碳合金叫做铸铁（生铁）
- 含碳量低于 2.1% 的铁碳合金叫做钢
    - 含碳量大于 0.6% 叫做高碳钢，硬度大，但塑性和韧性差，易碎
    - 含碳量小于 0.25% 叫低碳钢，软、韧性好，但硬度低


刀剑锻造：刀身用低碳钢，使其不易折断，刀刃用高碳钢，使其可以磨的极为锋利。


贝塞麦法炼钢（1856年）
- 铁水中吹入空气
    - 杂质被烧掉
        - 硅 -> 二氧化硅（炉渣）
        - 锰 -> 二氧化锰（炉渣）
    - 碳被氧化，碳 -> 一氧化碳
    - 铁被氧化，氧化铁
- 这些反应放出大量的热
- 炉内温度升高
- 滚烫的钢水
- 之后可以按精确的比例加入碳，得到精确比例的碳钢

一些问题：
- 如何控制铁的氧化？
    - 存在碳和其它杂质时，FeO 是一种氧的传递介质
    - 工人观察炉口火焰，当含碳量够低时，CO 明显减少，炉口火焰会突然减弱
- 为什么后来被淘汰了？
    - 难以脱磷
    - 空气中的氮气溶于钢水，影响钢的性能
    - 成分控制困难，依赖工人观察火焰
- 现代炼钢
    - 氧气转炉炼钢法：吹入高纯氧气
    - 电弧炉炼钢法：利用电弧提供热量（适合以废钢为主要原料炼钢）



| 钢材类型                          | 典型含碳量        | 主要特点           | 常见用途        |
| ----------------------------- | ------------ | -------------- | ----------- |
| 低碳钢（Low-Carbon Steel）         | 低于0.25%      | 塑性好、易加工、易焊接    | 建筑、钢板、普通结构件 |
| 中碳钢（Medium-Carbon Steel）      | 0.25%～0.60%  | 可通过热处理获得较高强度   | 轴、齿轮、弹簧     |

| 超高碳钢（Ultra-High-Carbon Steel） | 通常约1.0%～2.0% | 碳化物较多，耐磨但加工更困难 | 部分特殊工具钢     |



| 热处理状态              | 性能特点                 |
| ------------------ | -------------------- |
| 退火（Annealing）      | 较软，容易加工和成型           |
| 淬火（Quenching）      | 硬度显著提高，但脆性和内应力较大     |
| 淬火后适当回火（Tempering） | 降低脆性，在硬度、强度和韧性之间取得平衡 |

## 材料的指标

刚度、强度和硬度都是材料的力学性能（或称机械性能）指标，为了理解三者的意义，我们首先要知道：
- **弹性变形**：当外力去掉后能恢复到原来的形状和尺寸的变形。
- **塑性变形**：当外力去掉后不能恢复到原来的形状和尺寸的变形。

接下来，再来理解刚度、强度和硬度，就比较容易了：
- **刚度**：受力时抵抗弹性变形的能力。它描述了在受力情况下物体变形的难易程度。
    - 例子：一根很难弯曲的钢棒比一根容易弯曲的橡皮管具有更高的刚度。
    - 意义：某些零件的弹性变形量超过一定数值后，会影响机器工作质量，如机床的主轴、导轨、丝杠等。
    - 衡量：单位变形所需的力或力矩来表示，
    - 大小取决于零件的几何形状和材料种类（即材料的弹性模量）。
- **强度**：强度是物体在断裂或永久变形前所能承受的最大应力。
    - 例子：建筑中的钢梁需要很高的强度来支撑大楼的重量。
    - 强度是衡量零件本身承载能力（即抵抗失效能力）的重要指标，是机械零部件首先应满足的基本要求。
    - 按外力作用的性质不同，主要有屈服强度、抗拉强度、抗压强度、抗弯强度等，工程常用的是屈服强度和抗拉强度，这两个强度指标可通过拉伸试验测出。
    - 还可以分为静强度、疲劳强度（弯曲疲劳和接触疲劳等）、断裂强度、冲击强度、高温和低温强度、在腐蚀条件下的强度和蠕变、胶合强度等项目。
- **硬度**：硬度是物体抵抗局部塑性变形（如刮痕、凿痕）的能力。
    - 例子：钻石很难被划伤，因此它是非常硬的材料。
    - 意义：既可理解为是材料抵抗弹性变形、塑性变形或破坏的能力，也可表述为材料抵抗残余变形和反破坏的能力。硬度不是一个简单的物理概念，而是材料弹性、塑性、强度和韧性等力学性能的综合指标。
    - 分类：布氏硬度、洛氏硬度和维氏硬度等测试方法。
    - 硬度试验根据其测试方法的不同可分为静压法（如布氏硬度、洛氏硬度、维氏硬度等）、划痕法（如莫氏硬度）、回跳法（如肖氏硬度）及显微硬度、高温硬度等多种方法。
    - 硬度是一项综合力学性能指标，一般硬度高的材料，其强度也高。
- 挠度（Deflection）：物体在受力后发生的弯曲程度。
    - 例子：悬臂梁在受力后下垂的程度就是挠度。
- 弹性（Elasticity）：弹性是物体在去除外力后恢复到原始形状和尺寸的能力。
    - 例子：橡皮筋拉伸后能够恢复原状，因为它有很好的弹性。
- 韧性（Toughness）：材料吸收能量并在断裂前进行塑性变形的能力。
    - 例子：青铜比陶瓷具有更高的韧性，因为它在断裂前能弯曲和变形。
- 刚性（Rigidity）：物体抵抗变形的能力，不仅限于弯曲，也包括扭曲和压缩等。
    - 例子：钢结构的桥梁需要很高的刚性来确保它不会变形。
- 塑性（Plasticity）：物体在不发生断裂的情况下进行永久变形的能力。
    - 例子：金属在锻造过程中表现出很好的塑性，因为它们能在不破裂的情况下被拉伸和成型。





简单的总结：
- 延展性的能力叫韧性；韧度的典型指标是延伸率A(%)；
- 抗拉抗压能力叫强度；强度的典型指标是屈服强度Rp0.2(MPa)和抗拉强度Rm(MPa)；
- 工件的抗变形能力叫刚度；刚度的典型指标是弹性模量E(MPa)；
- 抗磨损能力叫硬度；硬度的典型指标是洛氏硬度HRB。

区别：
- 刚度和刚性：刚度主要指抵抗弯曲的能力，而刚性则指整体的抵抗变形能力，包括弯曲、压缩等。
- 强度和硬度：强度是物体承受最大应力的能力，而硬度是抵抗局部变形的能力。
- 弹性和塑性：弹性是去除外力后恢复原状的能力，而塑性是发生永久变形的能力。
- 韧性：韧性与强度和塑性相关，是材料在断裂前吸收能量的能力。







## 服装面料

天然纤维
1. 丝（丝绸、蚕丝）。
    - 公认的高级纤维。外观华丽、缎面光泽、穿着摩擦力低、容易褶皱、不保暖、易掉色、强度低。
    - 桑蚕丝（江浙一带）。光泽度好、强度低。
    - 柞蚕丝（河南、辽宁地区）。相比光泽度逊色、强度高。
    - 天丝不是丝，而是木材的提取物。
2. 麻
    - 人类最早使用的植物纤维
    - 亚麻（L，Linen）。更细腻，面料更柔软，主要产地欧洲。主要用于服装。
    - 苎麻（Ram，Ramie）。更坚韧，面料更厚实，面料颗粒感强，主要产地长江中下游。主要用于渔网、帐篷。
    - 麻纤维耐用。亚麻面料透气清爽，用于夏衣，非常易皱，出汗不粘皮肤。亚麻也曾代表高端。麻曾经代表清贫。
3. 棉（C，Cotton）。
    - 广泛使用。细绒棉、长绒棉、海岛棉。主要产地：新疆、埃及。海岛棉只生产于美洲的西印度群岛。
    - 细绒棉、长绒棉、海岛棉。光泽度、面料强度、品质递增。
    - 亲肤、保温、透气、容易变形、虫蛀。
4. 毛
    - 羊毛（W，Wool）。来自绵羊
    - 羊绒（CA，Cashmere）。来自山羊。柔软度、保温性、价格比羊毛高。
    - 澳大利亚：细支羊毛，用于服装。新西兰：粗支羊毛，用于羊毛毯、羊毛被。羊绒：内蒙古、新疆，国际顶级质量。
    - 聚温、吸水。羽绒服出现之前，御寒的首选。回弹、自洁、阻燃。易虫蛀、缩水、起球。
